# Coopanion v0.2.0

**Coo 专属 Persona 与引导里选人设，工作区版本历史，新版扩展市场，默认路径安装崩溃与 macOS 证书问题修复**

## 新功能

- **选人设**:新安装时的引导第 2 步(问完称呼后)可以选 Coo 是什么样的:小小的、好奇的 Coo,黏人的、靠谱的、活泼的、安静的，以及大肥鱼(Steam 版没有)。选中时 Coo 试穿对应配色、用那种性子说一句，确认后写入人设并换上配色。只在人设还是出厂原样时出现;之后人设由 Coo 自己修改。每份人设都有 11 种语言，换界面语言时没改过的人设跟着换。
- **性相配色**:装扮页新增五套 Coo 配色「性相：灯 / 杯 / 铸 / 心 / 冬」。
- **工作区版本历史**:Coo 每次写、改、追加、删除文件或保存图片都提交一个版本;每个版本的 Coopanion 第一次启动时给工作区打一个标签。`blobs/` 不进历史。Windows 版自带 MinGit 2.56.0,安装包大约大 30MB;macOS 和 Linux 使用系统里的 git。查看和回滚历史的页面还没有做。
- **PARTNER.md 与 partner/**:工作区里的 `PARTNER.md` 每次都整份放进 Coo 的系统前缀，不能用工具删除;Coo 会被提醒保持它精简，细节写进 `partner/` 目录下的文件，需要时再读。启动时，以前留下的同名文件(大小写不同的 `partner.md`、`Partner/` 目录、名为 `partner` 的文件)会合并到这两处，合并前的原样留在版本历史里。
- **新版扩展市场**(高级模式的扩展页):认证、官方、新品徽标和四级标签;可以直接点喜欢 / 不喜欢，在设置窗口里看评论、发评论(要先登录 GitHub);扩展的工具与事件、环境提示词、每个版本的更新说明、截图和支持的平台都能在详情里看到;标签不对可以点「反馈标签」。
- **按下才开麦**(语音设置，默认关):按下说话键时才打开麦克风，适合一开麦就切到通话模式的蓝牙耳机，按下后稍等再说。倾听气泡里可以取消这一句。

## 修复

- **默认路径安装崩溃**:安装器只按当前用户安装;数据目录写不进时弹出说明并退出。
- **macOS 连接失败**:Core 同时信任系统证书库，公司网络或代理换过证书时不再报 `UNABLE_TO_GET_ISSUER_CERT_LOCALLY`。
- **更新后 Core 启动失败**:启动时缺模块按 3 秒、10 秒、30 秒重试，不计入崩溃次数;失败后再次打开 Coopanion 会重启 Core。
- **工具返回异常值**:扩展工具返回了不合格式的值时记为失败，这一轮照常继续，不再没有回应。
- **旧会话无响应**:重启后读回会话时，删去找不到对应调用的工具回执。
- **切换服务后 400**:从 DeepSeek 等服务切到 ChatGPT 后，历史里其他服务记下的 id 不再发出。
- **扩展删不掉**:扩展发布不到 24 小时时卸载失败的问题修好了。
- 请求失败时，日志和报错带上具体原因。

## 改动

- **cortico 子模块升到 v0.2.0。** 已经装好的扩展照常能用:按旧接口写的扩展照常加载，扩展页详情里会提示它按旧契约编写;Cortico 下一个大版本起不再加载，作者升级发布后更新到新版即可。
- **设置窗口的叫法**:原来的「终端」页改叫「控制台」;连接状态只写「连接中… / 已连接 / 已断开」;窗口标题改为「设置 · 名字」。配置里的 `worlds.terminal` 与 `logging.console` 升级时自动迁到新名字。
- 中文版事件的标签改为英文 `[voice] [typed] [answer] [touch] [figure]`。Persona 自己放进上下文的系统行改为英文。
- 换成其他形象包时，气泡的选中框和进度点跟随形象包的主题色。
- 大肥鱼统一叫 DeepSeek 大肥鱼 / DeepSeek Chan。
- 系统提示词页：完整提示词预览移到底部，模板载入说明调整。

## 下载

- Windows x64:`Coopanion-Setup-0.2.0.exe`
- Apple 芯片 Mac:`Coopanion-0.2.0-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.2.0-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.2.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
