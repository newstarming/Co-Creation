# Coopanion v0.1.7

**Linux 支持**,以及 DeepSeek 大肥鱼的重新分层、新增眉毛。

- **Linux(x64)**:新增 `.deb`(Debian / Ubuntu)和 `.AppImage` 两种安装包。桌宠、设置窗口、说话键、FunASR 本地识别、让 Coo 操作电脑都能用;需要 X11 桌面,Wayland 会话下通过 XWayland 运行。数据在 `~/.config/Coopanion`,开机自动启动写进 `~/.config/autostart`。操作电脑用到 `xdotool` 和 `zenity`(deb 会自动装上)。
- **大肥鱼重新分层**:全部部件按「每个部件是一张完整的画」重画了一遍,边缘不再带被遮挡处的切口、锯齿和虚点。脸型照原画收窄,右脸颊补回轮廓线;尾巴重画成顺滑、逐渐变粗的弧线;下巴两侧的卷发、垂在身前的两束长发、左下的回卷、后腰蝴蝶结拆成单独的层,放回原画里它们该在的前后位置,走路、坐下、摆尾时不再互相穿插错位。
- **眉毛和上眼皮**:新增眉毛部件(在刘海下面画一次、透过刘海再淡淡画一次)和双眼皮褶线。眉毛随表情变化:惊讶时抬起,生气时眉头压低,难过、害羞时眉头上挑,眨眼时跟着下沉;褶线跟着眼睛睁闭。惊讶、爱心眼补上了完整眼白,表情脸上不再有多余的线。八套配色和装扮页缩略图同步更新。
