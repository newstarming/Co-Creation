# Coopanion v0.1.25

**可以用 ChatGPT 套餐额度驱动 Coo(测试中);设置窗口改为 Coopanion 自己的前端;修复装扮页的一处形象包安全问题**

## 新功能

- **用 ChatGPT 套餐登录(测试中)**:开始页、启动引导和高级模式的「模型供应商」页多了 ChatGPT 选项。点击「使用 ChatGPT 继续」，在浏览器里登录 ChatGPT 账号，就能用 Plus 或 Pro 套餐的额度驱动 Coo,不用填 API Key。
  - 额度和你在 ChatGPT、Codex 里的用量共用，请自己留意套餐额度。Plus 套餐有五小时额度，桌宠一直在线时用得比较快。
  - 额度用完时 Coo 会停在「思考中」，额度恢复后自动继续；在设置窗口的对话页给 Coo 发消息会打断等待。
  - 退出登录、删除这个连接时会撤销登录凭据。高级模式里 ChatGPT 连接不能复制。
  - 这项功能还没用真实账号跑完整流程，遇到问题欢迎在 GitHub 提 issue。

## 改动

- **设置窗口**:设置窗口改为 Coopanion 自己维护的前端，普通模式和高级模式的页面、外观都和之前一样。
  - 高级模式的「运行轨迹」改名「终端」，和 Cortico 的叫法一致。
  - 开始页的配色卡片改用 Cortico 新的调色盘折叠区，展开后颜色在左、组件试色在右。
  - 升级后第一次打开设置窗口时，左栏是否折叠、普通/高级模式、各折叠区的展开状态会回到默认一次，语言和配色不受影响。

## 修复

- **装扮页的形象包**:形象包清单里的字段不再被当作网页标记解析，含有这类字符的形象包会被拒收。建议只装来源可信的形象包。
- **关机回执**:设置窗口里关机后的回执，每一步的耗时不再显示成 `NaNs`。
- **气泡尾巴**:放大或在高分屏上，气泡尾巴两肩不再冒出一小块。

## 给自定义部署的说明

- 设置窗口不再在构建时覆盖 Cortico 控制台的源码，地址改为 `/coopanion/`,在独立的会话分区里运行，只能访问本机的 Core 和桌宠服务。普通模式只用 Cortico `docs/console.md` 列出的公开接口；高级模式的页面复制自 Cortico,会用到 Cortico 的内部接口。
- 部署设了控制台访问密码时，设置窗口打不开。Coopanion 默认不设密码。
