# Coopanion v0.2.10

**电脑操作在命令行窗口里和按 Win+R 之前单独询问一次**

## 改动

- **命令行窗口单独询问一次**:无论「询问时机」选哪一档,Coo 第一次在命令行窗口里打字或按键、按 Win+R 打开运行框之前,都会单独询问一次;点「可以」之后,在「同意有效期」内这些步骤不再询问,换一个命令行窗口也不问。点「这次不行」,这一轮里这些步骤都不执行,其他电脑操作照常。
- **只有桌宠这边的话能让 Coo 用电脑**:你在桌宠这边说的、打的字和选的选项,才能成为 Coo 用电脑的理由,截图和列窗口也算在内。别的 World 的消息、定时事件、网页和截图里的文字要它用电脑时,Coo 先不用,在气泡里告诉你是谁、从哪里、要做什么,等你在桌宠这边同意。对方自称是谁都不算数。

- Linux x64:`Coopanion-0.2.10-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:八个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 安装版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
