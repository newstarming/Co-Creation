# Coopanion v0.2.2

**ChatGPT 套餐与 DeepSeek 连接修复，桌宠右键菜单的扩展页面，扩展更新与市场读取修复**

## 新功能

- **扩展页面**:桌宠右键菜单多了「扩展页面」按钮，按 World 名列出已启用的扩展 World 声明的页面，点一项就打开。设置窗口自己的页面在应用窗口里打开，扩展自己起端口的页面交给系统浏览器。没有扩展声明页面时不显示这个按钮。

## 修复

- **ChatGPT 套餐连不上**:用 ChatGPT 套餐登录后，「开始」里连接时报「服务已应答，但响应格式不兼容」,对话也没有回应。现在能正常连接和对话。
- **DeepSeek 改用 Chat 协议后一直 400**:在高级模式里把 DeepSeek 的协议改成 Chat、开着思考时，每轮都报 `reasoning_content must be passed back`,Coo 不说话。现在本轮的工具调用会带上推理内容。
- **大肥鱼走路同手同脚**:走路时手臂和同侧的腿反向摆动。
- **自动更新装到另一个目录**:Windows 版自动更新改为装回正在运行的程序所在目录，`data\` 不会再被留在旧目录里。这条从 0.2.2 之后的更新起生效，更新到 0.2.2 这一次仍按旧规则。
- **更新扩展失败**:装着某个发布不到 24 小时的扩展时，更新、安装任何扩展都报 `ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION`。
- **扩展市场的标签、徽标和评分一直是空的**:连不上 raw.githubusercontent.com 的网络里，市场改从 GitHub 接口读索引;两处都读不到时沿用上次读到的。扩展图标和截图仍从 raw.githubusercontent.com 加载，那里连不上时不显示。
- **密钥读错**:密钥文件里有一行空的 `名字=` 时，不会再把下一行当成它的值，也不会把别家服务的密钥发出去。
- **重启后对话没有回应**:重启后已经进了上下文的事件不再重复投递，不会再因为重复的调用编号被服务拒绝。
- **整理上下文后重复回答**:上下文快满时刚回过的话，整理后不会再被漏掉，Coo 不再把同一个问题回答两遍。

- 随安装包带的 pnpm 升到 11.28.6。

## 下载

- Windows x64:`Coopanion-Setup-0.2.2.exe`
- Apple 芯片 Mac:`Coopanion-0.2.2-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.2.2-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.2.2-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
