# Coopanion v0.1.22

**设置窗口改版，可以把 Coo 导出为 OBS 画面，用量与成本可换算成人民币等货币，修复 Linux 上桌宠点不到、MiniMax 重复回复和安装失败后留下空安装**

## 新功能

- **OBS 画面**：「习惯」页最下面新增「其他」，打开「导出 OBS 画面」后会给出一个地址。在 OBS 添加「浏览器」来源，网址填写这个地址，宽高设为屏幕分辨率，Coo 和气泡就以透明背景叠在直播或录制画面上，位置与屏幕上一致。关闭时和原来一样。
- **设置窗口改版**：
  - 「开始」页把连接模型合成一个界面，并显示「我的桌宠」和配色方案；原来的「设置」页和齿轮键去掉了。
  - 左栏显示运行状态。
  - 「装扮」页改为上下布局，左栏图标换成衣服。
  - 「习惯」页分为通用、行为与互动、显示、音效、电脑操作、其他几节；每项先是设置，说明以小字放在下面，开关改为滑动开关。
- **右键菜单**：六个按钮排成两行三列，去掉「行为模式」（走动在「习惯」页或悬停按钮里修改），「隐藏桌宠」与「装扮」对换位置。
- **对话页**：换形象、换装扮、形象没能显示时各显示一行；Coo 的气泡与你的气泡左右对称。
- **用量与成本**：可以选择人民币、欧元、日元、韩元、新台币、雷亚尔或卢布显示，汇率在页面上直接填写，初始值为 2026 年 10 月 10 日的汇率。
- **腿可以垂到任务栏上**：Windows 上任务栏在底边时，桌宠窗口延伸到任务栏上方，坐在屏幕边沿时垂下的腿显示在任务栏上；地面仍在任务栏上沿。
- **语音输入页**：说话键单独一行，识别结果为空时有提示，音量条带名称。
- **文案**：界面文字统一了说法（走动、夜间模式、呼噜时长、称呼、同意有效期等），去掉了重复和多余的说明；繁体中文按台湾用词校对。

## 修复

- **Linux 上桌宠和气泡一直点不到**：X11 下鼠标穿透打开后，光标位置不再更新，身体、气泡和悬停按钮无法恢复点击。现在直接从 X11 读取光标位置。
- **MiniMax 重复回复或执行空的操作**：MiniMax 的流式响应会提前结束工具调用，再修改已结束的内容，导致重试。现在 MiniMax 改为读取完整响应后再执行。
- **图形界面安装中途失败后留下空安装**：杀毒软件或磁盘空间不足让解压失败时，安装器仍当作安装成功，登记并启动一个不存在的程序。现在会提示并中止，什么都不留下；一行命令安装时，失败的安装包会保留以便重试。
- **时间按电脑所在时区**：Coo 读到的时间和闹钟原先固定按北京时间，现在按电脑的时区。

## 下载

- Windows x64：`Coopanion-Setup-0.1.22.exe`
- Apple 芯片 Mac：`Coopanion-0.1.22-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.1.22-mac-x64.dmg` / `.zip`
- Linux x64：`Coopanion-0.1.22-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
