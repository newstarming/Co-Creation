# Coopanion v0.1.26

**普通模式的系统提示词页恢复为完整页面，新增「查看完整提示词」**

## 修复

- **系统提示词页**:v0.1.25 把普通模式的系统提示词页缩成了只能编辑人设，这是一处没有说明的改动。现在恢复成 v0.1.24 的完整页面：整条系统前缀分段编辑，带「重载当前 session」和「清空重开」，高级模式用的也是同一页。v0.1.25 发布说明里「普通模式和高级模式的页面都和之前一样」这句不对，在此更正。

## 新功能

- **查看完整提示词**:系统提示词页多了一个按钮，点击后展开模型实际收到的整条系统提示词，模板里的 `{{…}}` 已经替换好，再点击一次收起。

## 改动

- 桌宠 World 和服务商两个扩展包写上了作者 Pal AI Lab。
- cortico 子模块升到 v0.1.15。

## 下载

- Windows x64:`Coopanion-Setup-0.1.26.exe`
- Apple 芯片 Mac:`Coopanion-0.1.26-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.1.26-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.1.26-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
