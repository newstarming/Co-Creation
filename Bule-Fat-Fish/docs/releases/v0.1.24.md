# Coopanion v0.1.24

**大肥鱼新增冬装，启动引导用各语言问好，电脑操作并入桌宠；修复强杀后再也启动不了、空中接不住桌宠、OBS 画面抽动、镜像源下扩展市场为空**

## 新功能

- **大肥鱼的冬装**：DeepSeek 大肥鱼多了一套「冬装」：鲸鱼兜帽、带毛球的系带、毛绒边斗篷、条纹围巾、毛绒袖口和靴子。装扮页在配色下面多一行「服装」，女仆装和冬装都带全身缩略图，可以和任一配色搭配。毛球和围巾尾巴会随拎起、走路、转头摆动。
- **电脑操作并入桌宠**：电脑操作不再是单独的 World，「习惯」页的开关即时生效，高级模式的桌宠 World 页多一盏「操作引擎」灯，悬停可看能否操作和询问档位。升级时原来的启用状态和询问档位会自动搬过去。
- **启动引导**：
  - 选语言那一页不再用英语提问，Coo 叫一声「Coo! Coo...?」，每张卡片用这门语言问好，「Continue」换成对勾。
  - 选模型服务时点「More…」直接在气泡里展开其余服务，不用再按一次确认。
- **装扮页「形象」一行**：每个形象包那一格固定显示包自己的小图，不再随当前配色、服装变化。

## 修复

- **强杀后再也启动不了**：Coopanion 被强制结束后，如果它原来的进程号被别的程序占用，之后每次启动都会被拦下。现在能认出进程号已换成别的程序并正常启动。确实有另一个 Coopanion 进程占着数据时，不再每 3 秒反复重启，而是弹框说明是哪个进程，结束它后从托盘菜单「重新启动」即可。
- **空中接不住桌宠**：Coo 下落或被扔出时按住鼠标没反应，要等落地才能拎。现在半空中一按就能接住。
- **OBS 画面掉帧、抽动**：OBS 叠加层改为跟着桌宠画的每一帧截取，按画出的时刻显示，帧率跟着桌宠设置走。要看到 60 帧，需要在 OBS 浏览器来源里设自定义帧率，README 有说明。
- **扩展市场为空**：npm 源设成 npmmirror 等镜像时，扩展市场一直显示没有扩展。现在能列出来；确实为空时会写出正在用的源地址和换源方法。
- **设置窗口的颜色**：选了不是预设的配色与服装组合（比如 Claude 配色 + 冬装）时，设置窗口按配色取颜色，不再退回 DeepSeek 蓝。
- **高级模式桌宠 World 页**：不再出现加载失败的「对话」标签。

## 给自定义部署的说明

- 电脑操作的十个工具从 `cua_*` 改名为 `pet_cua_*`，配置从 `worlds.cua` 移到 `worlds.desktop-pet.cua`（启动时自动迁移）。改过桌宠环境提示词的，要自己加上 `{{pet.cua}}`，否则模型看不到电脑操作的说明。
- 形象包预设里的 `thumb` 字段不再使用，写了也照常加载。

- Apple 芯片 Mac：`Coopanion-0.1.24-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.1.24-mac-x64.dmg` / `.zip`

- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
