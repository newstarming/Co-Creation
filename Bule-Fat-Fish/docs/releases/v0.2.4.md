# Coopanion v0.2.4

**电脑操作支持多显示器和局部放大，输入的话留成气泡，Windows 便携版，换了目录时询问继承数据**

## 新功能

- **电脑操作：多显示器**:一次截一块显示器，从左到右编号，Coo 可以指定截哪块。窗口列表写明每个窗口在哪块屏上。截图之后显示器有变化时，Coo 的输入会被拒绝，要先重新截图。
- **电脑操作：局部放大**:Coo 可以按原始分辨率重截截图里的一块，看清缩小后读不出的小字。
- **电脑操作：开关即时生效**:在「习惯」页打开或关掉电脑操作后不用重启。关着时 Coo 知道有这个功能，征得同意后会打开设置窗口的对应位置。
- **电脑操作：首次打开先看风险说明**:第一次打开时弹出风险说明，确认后才开启。
- **输入的话留成气泡**:桌宠打字框、语音识别、对话页和设置窗口里说的话，作为气泡留在 Coo 旁边，最多 3 条。Coo 回完话 1 秒后淡出，Coo 没回 8 秒后淡出;点一下语音气泡就关掉。识别完成的语音气泡不再显示「已识别」。
- **气泡尺寸、字体尺寸**:「习惯」页「显示」分区多了两个滑块，0.8–1.6,和 Coo 的「大小」互不影响。默认档下 Coo 改这两项前会先问你。
- **Windows 便携版**:新增 zip 便携版，解压就能运行，数据只在它自己的文件夹里，复制整个文件夹就是另一只，最多同时运行 5 只。便携版不自动更新，有新版本时设置窗口给下载链接。用法和升级方法见 README。

## 修复

- **换了安装目录后失忆**:Windows 安装版的程序换了目录、旁边没有数据时，会询问继承之前的数据还是新建一只，显示数据路径和最后一次启动时间。之前的数据所在位置找不到时，可以重试、选择文件夹、新建或退出。从 0.2.4 起记录数据位置，在这之前已经分成两份的安装找不回来。
- **自动更新时引导手动下载**:自动更新正在下载时，气泡和设置窗口不再给去 GitHub 下载安装包的链接，只有下载失败时才给。
- **托盘「开机自动启动」勾不上**:Windows 上开启后托盘一直显示没勾上，也关不掉。
- **端口全被占时误报「刚刚更新过」**:本地端口 17788–17792 都被占用时，不再重试 5 次后提示「如果刚刚更新过……」，改为提示可能已有几只在运行或别的程序占用了端口。
- **桌宠窗口起不来时日志没有记录**:桌宠窗口进程自行异常退出时，core.log 写一条警告和退出码。

## 改动

- **cortico 子模块升到 v0.2.3**:明文推理回放不再带签名块，本地上下文估算只计一份推理;扩展讨论页未登录时「在 GitHub 上查看讨论」链接正确。
- README:电脑操作默认关闭，写明打开方式和多显示器。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.4.exe`
- Windows x64 便携版:`Coopanion-0.2.4-win-x64-portable.zip`
- Apple 芯片 Mac:`Coopanion-0.2.4-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.2.4-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.2.4-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:八个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 安装版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
