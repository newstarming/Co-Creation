# Coopanion v0.2.1

**扩展安装修复**

## 修复

- **卸载扩展后再装失败**:卸载过一个扩展后，只要装着发布不到 24 小时的扩展，再装扩展就会失败。现在装卸都能完成。
- **带原生模块的扩展装不上**:cortico-world-canvas、cortico-world-asr 这类要编译原生模块的扩展，安装时报失败、装上后起不来，之后每次安装也都报失败。现在扩展自己依赖的原生模块在安装时构建;以前装上但没构建的，下一次安装任意扩展时补上。更深一层依赖的构建脚本仍不运行，安装结果里写出包名和放行办法。

## 改动

- cortico 子模块升到 v0.2.1。

## 下载

- Windows x64:`Coopanion-Setup-0.2.1.exe`
- Apple 芯片 Mac:`Coopanion-0.2.1-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.2.1-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.2.1-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
