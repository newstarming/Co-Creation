# Coopanion v0.1.23

**Coo 能在对话页发图片，启动引导先选语言，设置窗口侧栏可以折叠，外发光距离可调；修复桌宠隐藏后仍有音效、Linux 上桌宠接管鼠标后不交还**

## 新功能

- **对话页显示 Coo 发的图片**：Coo 可以把生图结果、电脑操作的截图、你发来的图或工作区里的图发到「对话」页，显示为缩略图，点开看原图。图片只显示在对话页，头顶气泡里不显示。
- **启动引导先选语言**：引导的第一页用英语询问使用哪种语言，11 种语言各以自己的写法列出。第一次启动默认选中 English，之后从「开始」页再次运行向导时默认选中当前语言。没连模型时定时询问 API Key 的气泡不再插到引导前面。
- **设置窗口侧栏可折叠**：折叠后只显示图标，字标收成 Coo 标志；展开或折叠的选择会被记住。
- **外发光距离可调**：「习惯」页「大小」下面新增「外发光」滑条，0 为关闭，1–16 px，默认 7。
- **界面语言补齐**：扩展页的 World 名字、模型连接与扩展安装的报错和回执、关机时的检查结果都跟着界面语言显示，切换语言后不用重启。

## 修复

- **桌宠隐藏后仍有音效**：全屏自动隐藏或手动隐藏桌宠后，走动、表情等音效照样会响。现在隐藏期间不出声。
- **Linux 上桌宠接管鼠标后不交还**：桌宠页面卡住或重载时，整个桌面可能一直点不到。现在桌宠窗口只在页面持续确认时接管鼠标，页面没有回应约 2 秒后自动交还。
- **光晕被误关**：有对话气泡或 Coo 刚掉下来时，光晕不再被错误地关掉。
- **向导气泡**：初始向导里选卡片时的气泡，在拖动、扔出或下落 Coo 时跟着走。
- **窄气泡的尾巴**：还没出字的窄气泡，下方的小三角居中；尖端与边框一样粗。
- **设置窗口细节**：
  - 「开始」「装扮」页的桌宠预览不再闪白或闪错配色。
  - 复选框与开关同色。
  - 默认窗口加宽到 1200，「开始」页的模型一栏排成两行。
  - 窄窗口下弹窗和看大图的浮层显示在顶栏之上。
- **右键菜单**：名字很长时菜单不再被撑宽。

- Windows x64：`Coopanion-Setup-0.1.23.exe`
- Apple 芯片 Mac：`Coopanion-0.1.23-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.1.23-mac-x64.dmg` / `.zip`

- `SHA256SUMS.txt`：七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`：自动更新读的版本信息，不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
