# Coopanion v0.1.8

**电脑操作的询问分档**:可以按需要放宽 Coo 用电脑前问你的频率。

- **什么时候先问你**:高级模式「电脑操作」页新增这一项,从严到松四档:
  - `ask-each-turn`(默认,和原来一样):每一轮第一次看屏幕或动鼠标键盘之前问一次。
  - `ask-before-acting`:截图、列窗口不问;每一轮第一次动鼠标键盘之前问。
  - `ask-once`:截图、列窗口不问;动鼠标键盘之前问一次,同意后「同意管多久」(默认 30 分钟,1–1440 可调)内不再问。
  - `never-ask`:都不问。
- 气泡里的问句跟着档位变;拒绝只挡住这一轮要问的操作,只问操作的两档里截图照常。Coo 收到的操作说明也按当前档位写。
- 你一碰鼠标键盘它就让位、登录密码付款交给你、发送删除提交前先问你,这些不变。已有的设置升级后仍是 `ask-each-turn`。
